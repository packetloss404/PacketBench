# Documentation location and audit records

The repository's single navigation entry is [dev/README.md](../dev/README.md).
Use [current status](../dev/current-status.md), [ROADMAP](../ROADMAP.md),
[backlog](../backlog.md) and [HANDOFF](../HANDOFF.md) for current execution.
The [catalog](../dev/documentation-map.md) lists this folder and all tracked
Markdown, including dated evidence and archives.

This folder retains September 2026 audit, dependency, operations and handoff
snapshots plus local report assets. Their exact source/package scope is
historical. `runbooks.md` remains useful operational reference, but commands
must be checked against the current source and current deployment identity.

Public user documentation lives in the separate
[ianlan-docs repository](https://github.com/packetloss404/ianlan-docs). This audit
does not update or publish that site, and it does not recreate missing July/
August report files under this directory.
