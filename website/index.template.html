A few useful details

Before you
open the source.

Is this a browser app?+

{{APP_NAME}} is a native desktop application built with Tauri and Rust. This page introduces the product; the repository contains the source, setup instructions, and build records.

Does it replace my coding agent?+

It provides the environment around the agents you use: terminal panes, API conversations, project organization, permissions, and review. CLI and API paths remain distinct.

Can I work on remote projects?+

SSH workspaces and remote execution paths are supported. Remote hosts require their own compatible tools and configuration. The separate Remote Agents relay feature remains gated; it is not a general hosted service.

Where should I start?+

Start with the GitHub README for prerequisites and setup. Read the current handoff for acceptance status, and use the documentation to explore the workflow.
