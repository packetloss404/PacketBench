# Historical plans and evidence

This directory preserves completed, superseded and retired work. It is not an
implementation queue. Start at [the documentation hub](../README.md),
[current status](../current-status.md) and [backlog](../../backlog.md).
The [complete catalog](../documentation-map.md#archive) lists every file here.

## Program families

- [Syndicate](./syndicate/README.md): separated product and removed execution
  target. Do not resume its old deployment requests or restore that integration.
- [Tile program](./tile-program/README.md): its Agents-tab-retirement direction
  was superseded by first-class Agents plus CLI-first Workspaces.
- [Workspace history](./zen-workspace/README.md): context for shipped project,
  prompt-library and layout features; current residuals live in backlog.
- [Dictation predecessor](./vibetotext/README.md): historical product work.
- `moat/`, `quadcode/`, `bridgemind/`: historical feature/positioning studies.
  Appearance in this archive does not reactivate a feature, Cost Dashboard or
  comparator claim.
- The remaining dated reviews, planner records, old backlog and convergence
  queues are listed individually in the catalog. The autonomous Flight planner
  remains retired; present Flight planning uses the current explicit contract.

Historical checkboxes, owner questions, URLs, deployment targets and code-line
references describe their recorded date. Use current contracts and decisions
before execution. Later source fixes do not retroactively change an old test
result. Missing moved report references are identified in the catalog.
